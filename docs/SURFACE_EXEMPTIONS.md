# Surface exemptions

Registry of public surfaces that are **exempt from the result-contract / `--json`
coverage requirement**, each with a stated reason.

Parsed by `core.surface_inventory.load_exemptions()`. A row is only honoured when
it has a non-empty reason — `-`, `—`, `TODO` and blanks are ignored, so a
half-filled row fails the check rather than silently passing it. An unwrapped
surface that is not listed here is a coverage failure, by design: silent skips
are the failure mode this file exists to prevent.

## What an exemption does and does not mean

| | |
|---|---|
| **Exempts from** | emitting a single contract envelope / honouring global `--json` |
| **Never exempts from** | budget prechecks, permission gates, workspace jail, audit logging |

This distinction matters for `cli:split-tui` and `cli:agent-tui`, which are
classified `spend`. They are exempt here because a long-lived terminal session
cannot emit one JSON object — **not** because they may skip a spend gate. The
Phase 2 spend-ceiling test deliberately ignores this file.

## Adding a row

1. Confirm the surface genuinely cannot emit a contract envelope. "It would be
   awkward" is not a reason; "it streams a terminal session for the lifetime of
   the process" is.
2. Add the row below with a reason that would still convince a reviewer in six
   months.
3. If the reason stops being true, delete the row. A stale exemption is
   indistinguishable from an unnoticed regression.

## CLI — interactive terminal sessions

These own the terminal for the duration of the process and exit on user action.
There is no single result to serialize.

| Surface | Classification | Reason |
|---|---|---|
| `cli:chat` | interactive | Long-lived REPL session; output is a conversation transcript, not one result |
| `cli:memory-chat` | interactive | Long-lived REPL over memory palace; same shape as `chat` |
| `cli:tui-live` | interactive | Full-screen live TUI holding raw terminal input |
| `cli:mouse` | interactive | Raw terminal mouse-input demo; no result value |
| `cli:agent-tui` | interactive | Full-screen agent TUI; per-turn results are rendered in-pane |
| `cli:split-tui` | interactive | Split-pane TUI session. Spend still gated at `ModelCaller`; exemption is contract-only |
| `cli:install` | interactive | Guided install wizard; prompts for choices and writes config |
| `cli:init` | interactive | Guided project scaffolding wizard |
| `cli:onboard` | interactive | Guided onboarding quest; prompts throughout |
| `cli:members` | interactive | Interactive member picker |
| `cli:mcp-serve` | read_only | Blocks serving MCP over stdio for the process lifetime; stdout is the JSON-RPC channel, so anything else printed there corrupts the protocol |

## CLI — shell-protocol output

| Surface | Classification | Reason |
|---|---|---|
| `cli:completion show` | read_only | Must emit a raw shell script to stdout; any wrapper would corrupt the script the shell sources |

## HTTP — HTML pages

Browser-facing pages returning `HTMLResponse`. Their JSON counterparts under
`/api/*` are **not** exempt and must carry the contract.

| Surface | Classification | Reason |
|---|---|---|
| `http:GET /` | read_only | HTML home page |
| `http:GET /console` | read_only | HTML management console |
| `http:GET /management.html` | read_only | HTML management console alias |
| `http:GET /dashboard` | read_only | HTML dashboard page; data comes from `/api/dashboard` |
| `http:GET /graph` | read_only | HTML graph visualizer; data comes from `/api/agent-graph` |
| `http:GET /palace` | read_only | HTML memory-palace browser; data comes from `/api/palace` |
| `http:GET /charts` | read_only | HTML charts page |
| `http:GET /cli-pool` | read_only | HTML CLI-pool page; data comes from `/api/cli-pool` |
| `http:GET /terminals` | read_only | HTML terminals page |
| `http:GET /mcp` | read_only | HTML MCP tool browser; data comes from `/api/mcp/tools` |
| `http:POST /api/charts/render` | mutating | Returns rendered chart HTML, not JSON. Under `/api/*` but an `HTMLResponse`, so the contract middleware correctly skips it |

## HTTP — framework-owned routes

Generated by FastAPI, not by this project. Not ours to wrap.

| Surface | Classification | Reason |
|---|---|---|
| `http:GET /docs` | read_only | FastAPI-generated Swagger UI |
| `http:GET /docs/oauth2-redirect` | read_only | FastAPI-generated OAuth2 redirect shim |
| `http:GET /redoc` | read_only | FastAPI-generated ReDoc UI |
| `http:GET /openapi.json` | read_only | FastAPI-generated OpenAPI schema; its shape is fixed by the spec |

## HTTP — foreign protocol envelope

| Surface | Classification | Reason |
|---|---|---|
| `http:POST /mcp` | mutating | JSON-RPC 2.0 bridge; the response shape is fixed by the MCP spec. Contract is applied one layer in, by `mcp_safety.wrap_mcp_tool` on each dispatched tool |
| `http:DELETE|GET|POST|PUT /v0/management/{mgmt_path:path}` | mutating | Reverse-proxy gateway passthrough for CLIProxyAPI upstream daemon management protocol; response shape dictated by daemon |
| `http:GET /v1/models` | read_only | Reverse-proxy gateway passthrough for CLIProxyAPI OpenAI-compatible models discovery protocol; response shape dictated by upstream |

## Not exempt — deliberately

Recorded so nobody re-litigates them:

- **`cli:completion install`** — writes to shell config. Has a real result
  (what was written, where) and must report it under contract.
- **Every `/api/*` route** — these exist to be consumed by automation. If one
  cannot carry the contract, that is a bug in the route.
- **Streaming commands** — the per-chunk path is uncontracted by design, but the
  final aggregate result is contracted via `call_stream_complete`. That is a
  documented shape, not an exemption.
